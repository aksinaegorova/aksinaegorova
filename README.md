### 💻 Как я использую GitHub

Для меня GitHub — это не просто хранилище кода, а центр моего профессионального роста:

| 🔄 **Практика** | 🛠 **Инструменты и подходы** |
| :--- | :--- |
| **Контроль версий** | Пишу осмысленные *Commit Messages*, работаю с ветками (*Git Flow*), оформляю аккуратные *Pull Requests*. |
| **Документация** | Убеждена, что хороший *README* — это лицо проекта. Всегда структурирую описание, добавляю скриншоты и инструкции по запуску. |
| **CI/CD** | Экспериментирую с *GitHub Actions* для автоматизации тестов и проверки стиля кода (linting) в моих учебных проектах. |
| **Open Source** | Изучаю архитектуру чужих репозиториев, учусь читать чужой код и участвовать в командной разработке. |
